# Contributing to The Hunter Archive

Thank you for your interest in contributing to **The Hunter Archive**!

## How to Contribute

### 1. Suggesting New Writeup Sources
If you know a great security blog, RSS feed, or GitHub repository containing bug bounty writeups:
- Open a GitHub issue with the tag `source-request`.
- Or submit it directly in the live app at **[https://hunter-archive.vercel.app/](https://hunter-archive.vercel.app/)** using the **`＋ Request Source`** button!

### 2. Submitting Code Improvements
1. Fork the repository on GitHub: `https://github.com/jojin1709/hunter-archive`.
2. Create a new topic branch: `git checkout -b feat/your-feature-name`.
3. Ensure code builds cleanly without errors: `npm run build`.
4. Submit a Pull Request targeting the `main` branch.
