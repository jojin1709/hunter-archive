# Security Policy

## Supported Versions

We actively issue security updates for the latest production build of **The Hunter Archive**.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

**The Hunter Archive** takes security issues seriously. If you discover a vulnerability or security flaw in this application or dataset pipeline:

1. **Do NOT open a public GitHub issue** for undisclosed security vulnerabilities.
2. Please contact the project maintainer **JOJIN JOHN** directly via GitHub: **[https://github.com/jojin1709](https://github.com/jojin1709)**.
3. Include details of the vulnerability, proof-of-concept steps, and potential impact.

We will acknowledge receipt of your report within **24 hours** and provide regular status updates regarding remediation.

## Responsible Disclosure Guidelines

* Please allow reasonable time for fixes to be applied before publicly disclosing any finding.
* Do not attempt to access, mutate, or destroy data belonging to other users.
* Test against your local development environment whenever possible.
